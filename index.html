Что такое OSINT?

Open Source Intelligence (OSINT) — методология сбора и анализа информации из общедоступных источников для получения разведывательных данных.

Social OSINT

Анализ социальных сетей, профилей, связей и активности пользователей в открытых источниках.

Twitter Facebook VK Instagram

Исследование телефонных номеров, поиск владельцев, связанных аккаунтов и истории активности.

Social OSINT

Social OSINT фокусируется на сборе и анализе информации из социальных сетей и платформ, где пользователи добровольно делятся данными.

Основные источники:

  • Twitter (X) - анализ твитов, связей, активностей
  • Facebook/Instagram - профили, группы, мероприятия
  • ВКонтакте - наиболее полные данные в Рунете
  • LinkedIn - профессиональные связи и история работы
  • Telegram - каналы, группы, публичные чаты

Методы анализа:

  • Анализ графа связей между пользователями
  • Идентификация по фотографиям и аватарам
  • Анализ поведенческих паттернов
  • Кросс-платформенная корреляция аккаунтов
  • Временной анализ активности
# Пример поиска по социальным сетям
python3 sherlock username
python3 social-analyzer -u username -p all

Phone OSINT

Phone OSINT специализируется на исследовании телефонных номеров и связанной с ними информации.

Возможности:

  • Определение оператора и региона номера
  • Поиск аккаунтов, привязанных к номеру
  • Проверка на наличие в базах утечек
  • Геолокация по данным вызовов (при наличии доступа)
  • Анализ паттернов звонков и сообщений

Этические границы:

  • Использование только публичных баз данных
  • Отказ от методов социальной инженерии
  • Соблюдение законодательства о персональных данных
  • Ограничение на коммерческое использование без согласия
# Проверка номера через открытые API
curl -X GET "https://api.opencagedata.com/geocode/v1/json?q=+79161234567"
python3 phoneinfoga -n +79161234567

Инструменты OSINT

Профессиональные инструменты для сбора и анализа информации из открытых источников.

Sherlock

Python Username Social

Поиск аккаунтов по username в сотнях социальных сетей и платформ. Автоматическая проверка наличия аккаунта с заданным именем пользователя.

GitHub
# Установка Sherlock
git clone https://github.com/sherlock-project/sherlock.git
cd sherlock
python3 -m pip install -r requirements.txt

# Базовое использование
python3 sherlock username

# Поиск нескольких пользователей
python3 sherlock user1 user2 user3

# Сохранение результатов в файл
python3 sherlock username --output results.txt

Особенности:

  • Поддержка 300+ социальных сетей
  • Цветовой вывод результатов
  • Настройка тайм-аутов и прокси
  • Экспорт в JSON/CSV форматы

PhoneInfoga

Go Phone Recon

Мощный инструмент для OSINT разведки телефонных номеров. Проверяет номера через открытые API и базы данных.

GitHub
# Запуск через Docker
docker run -it sundowndev/phoneinfoga scan -n +79161234567

# Установка из исходников
git clone https://github.com/sundowndev/phoneinfoga
cd phoneinfoga
go build

# Сканирование номера
./phoneinfoga scan -n +79161234567

# Использование прокси
./phoneinfoga scan -n +79161234567 -p http://proxy:8080

Возможности:

  • Определение страны и оператора
  • Поиск в социальных сетях
  • Проверка на утечки
  • Валидация формата номера

theHarvester

Python Email Subdomain

Сбор электронных писем, поддоменов, IP-адресов и URL из публичных источников для этапа разведки.

GitHub
# Установка
git clone https://github.com/laramies/theHarvester.git
cd theHarvester
pip3 install -r requirements.txt

# Базовый поиск
python3 theHarvester.py -d example.com -b all

# Поиск только email
python3 theHarvester.py -d example.com -b google -e

# Сохранение результатов
python3 theHarvester.py -d example.com -b all -f results.html

Источники данных:

  • Google, Bing, Yahoo поиск
  • LinkedIn, Twitter, PGP ключи
  • Shodan, VirusTotal, ThreatCrowd
  • DNSdumpster, Netcraft, SSL сертификаты

ExifTool

Perl Metadata Forensics

Чтение, запись и редактирование метаданных в изображениях, аудио и видео файлах.

Website
# Просмотр всех метаданных
exiftool image.jpg

# Просмотр конкретных тегов
exiftool -T -filename -createdate -GPSPosition image.jpg

# Удаление метаданных
exiftool -all= image.jpg

# Экспорт метаданных в JSON
exiftool -json image.jpg > metadata.json

# Пакетная обработка
exiftool -ext jpg -GPSLatitude -GPSLongitude .

Анализируемые данные:

  • EXIF данные камеры
  • Геолокационные координаты
  • Дата и время съемки
  • Информация об авторских правах
  • Технические параметры файла

Гайды и Инструкции

Пошаговые руководства по использованию OSINT инструментов и методологий.

Базовый OSINT пайплайн

Шаг 1: Определение цели

Четко сформулируйте, что именно вы ищете. Это может быть информация о человеке, компании, событии или цифровом следе.

Шаг 2: Сбор открытых данных

Используйте поисковые системы, социальные сети, публичные базы данных и специализированные инструменты для сбора информации.

# Пример сбора данных о домене
theHarvester -d target.com -b all
subfinder -d target.com
assetfinder --subs-only target.com

Шаг 3: Анализ и корреляция

Собранные данные нужно проанализировать, выявить связи и закономерности, отделить важную информацию от шума.

Шаг 4: Визуализация

Представьте результаты в наглядном виде: графы связей, временные линии, карты географических данных.

# Создание графа связей в Maltego
1. Импорт собранных данных
2. Настройка трансформов для анализа связей
3. Визуализация графа
4. Экспорт в отчет

Шаг 5: Формирование отчета

Структурируйте найденную информацию в отчет, который будет понятен заказчику или для дальнейшего использования.

Анализ EXIF данных

Извлечение координат GPS из фотографий.

# Использование ExifTool
exiftool -GPSLatitude -GPSLongitude image.jpg

# Если координаты в градусах/минутах/секундах
exiftool -c "%.6f" -GPSPosition image.jpg

# Удаление геотегов
exiftool -GPS*= image.jpg

Методологии Hacking

Изучение методов разведки, анализа уязвимостей и защиты систем.

Пассивная разведка

Сбор информации без прямого взаимодействия с целевой системой. Использование открытых источников, поисковых систем, архивов.

Активная разведка

Неинтрузивное сканирование сетей, DNS запросы, анализ сервисов. Определение инфраструктуры без эксплуатации уязвимостей.

Социальная инженерия

Анализ человеческого фактора. Изучение сотрудников, их связей, привычек и потенциальных векторов атаки.

Анонимность в сети

Использование VPN, Tor, прокси. Управление цифровым следом. Избегание идентификации по поведенческим паттернам.

Безопасная коммуникация

Шифрование трафика, использование защищенных протоколов. OTR для мессенджеров, PGP для email.

Управление идентификацией

Создание и поддержание отдельных идентичностей для разных активностей. Контроль cross-platform корреляции.
